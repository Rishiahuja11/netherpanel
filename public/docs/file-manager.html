File Manager

Browse, edit, upload and download files in your server directory directly from the web interface.

Browsing Files

Click Files in the server sidebar to open the file manager. You'll see the server's root directory with all files and folders.

  • Directories are shown with a folder icon and can be clicked to navigate into them.
  • Files show their size and last modified date.
  • Use the breadcrumb path at the top to navigate back to parent directories.

Editing Files

Click any text file (e.g. server.properties, bukkit.yml) to open it in the built-in editor.

  • Make your changes in the text editor.
  • Click Save to write the changes back to disk.
  • Max file size for editing: 5MB.

Binary files (jars, phars, images) cannot be edited in the web editor. Download them, modify locally, and re-upload.

Uploading Files

  1. Navigate to the directory where you want to upload.
  2. Click the Upload button.
  3. Select one or more files from your device (max 10 files per upload).
  4. Files are uploaded to the current directory.

Downloading Files

  1. Click the Download button next to any file.
  2. The file downloads to your device's download folder.

Creating Files & Directories

  • New Directory — click the New Folder button and enter a name.
  • New File — create a file by writing content in the editor and saving with a new path.

Deleting Files

Select a file or directory and click Delete. Confirm the action in the dialog. This permanently removes the file from disk.

Renaming / Moving

Use the rename action to change a file's name or move it to a different directory within the server.
