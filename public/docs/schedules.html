Schedules

Automate repetitive server tasks with cron-based schedules. Restart your server nightly, create periodic backups, or run custom commands on a timer.

Creating a Schedule

  1. Open your server and click Schedules in the sidebar.
  2. Click Create Schedule.
  3. Fill in the fields:
    • Name — a descriptive name (e.g. "Nightly Restart").
    • Cron Expression — timing pattern (see below).
    • Action — what to do (restart, backup, stop, start, or custom command).
  4. Click Create.

Cron Expressions

Schedules use standard cron syntax with five fields:

cron
┌───────── minute (0–59)
│ ┌─────── hour (0–23)
│ │ ┌───── day of month (1–31)
│ │ │ ┌─── month (1–12)
│ │ │ │ ┌─ day of week (0–7, 0 and 7 = Sunday)
│ │ │ │ │
* * * * *

Common Patterns

CronDescription
0 3 * * *Every day at 3:00 AM
0 */6 * * *Every 6 hours
0 0 * * 0Every Sunday at midnight
*/30 * * * *Every 30 minutes
0 4 * * 1-5Weekdays at 4:00 AM
0 2 1 * *First day of each month at 2:00 AM

Available Actions

ActionDescription
restartStops the server, waits, then starts it again
stopStops the server
startStarts the server
backupCreates a new backup
commandRuns a custom command in the server console

Managing Schedules

  • Toggle on/off — disable a schedule without deleting it.
  • Edit — change the cron expression, action or name.
  • Run Now — manually trigger a schedule immediately.
  • Delete — permanently remove a schedule.

Common Schedule Examples

Nightly Restart

Restart your server every day at 3 AM to clear memory and apply updates:

config
Name: Nightly Restart
Cron: 0 3 * * *
Action: restart

Hourly Backups

Create a backup every hour during peak play times:

config
Name: Hourly Backup
Cron: 0 10-22 * * *
Action: backup

Weekly World Backup

Full backup every Sunday at midnight:

config
Name: Weekly Backup
Cron: 0 0 * * 0
Action: backup

Auto-Save Command

Run a save-all command every 15 minutes:

config
Name: Auto Save
Cron: */15 * * * *
Action: command
Command: save-all
