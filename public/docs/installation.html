Docs / Installation

Installation

NetherPanel runs natively on Termux (Android). You can also install it on Linux or Windows. Every platform follows the same clone → setup → start flow.

Termux (Android) — recommended

1. Install Termux

Download from F-Droid (recommended) or the GitHub releases page. Avoid the Play Store build — it is outdated.

2. Clone and setup

bash
pkg update && pkg upgrade -y
pkg install git -y

git clone https://github.com/Rishiahuja11/netherpanel.git
cd netherpanel
bash setup.sh

The setup script will install Node.js, proot-distro, the Ubuntu distribution and Java 25 inside it, plus all npm dependencies.

3. Start

bash
bash start.sh

Open http://localhost:3000 in your phone's browser. Default credentials: admin / admin123.

proot-distro provisioning (manual)

If you ever need to recreate the Ubuntu environment:

bash
proot-distro install ubuntu
proot-distro login ubuntu -- bash -c "apt update && apt install -y openjdk-25"

Java servers must run inside proot Ubuntu. PocketMine-MP runs natively — no proot needed for Bedrock PHP servers.

Linux (Debian/Ubuntu)

If your device runs a full Linux distribution (e.g. a VPS or WSL), the same steps work:

bash
sudo apt update && sudo apt install -y git nodejs npm
git clone https://github.com/Rishiahuja11/netherpanel.git
cd netherpanel
bash setup.sh
bash start.sh

Node.js 18+ is recommended. If you need proot-distro for Java servers, install it separately — the setup script handles this on Termux but not necessarily on desktop Linux.

Windows (WSL)

  1. Enable WSL 2 and install an Ubuntu distribution from the Microsoft Store.
  2. Open your WSL terminal and install Node.js: sudo apt install -y nodejs npm
  3. Clone and run setup as above.
  4. The panel is accessible at http://localhost:3000 from Windows.

After install

CommandWhat it does
bash setup.shInstall all dependencies (idempotent — safe to re-run)
bash start.shStart the panel on port 3000
node create-admin.js <user> <pass> [email]Create an admin user

The admin / admin123 account is seeded automatically on first launch. Change the password immediately after logging in.
