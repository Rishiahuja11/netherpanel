Public Status & Share Pages

Show the world what's running — without giving away any login access.

The public status page

NetherPanel ships two read-only, public pages that need no authentication:

  • /status — a clean overview of every server, live player counts, MOTD, version and RAM usage.
  • /status/:slug — raw JSON for one server (great for bots or embed scripts).

You can use the status page as a public homepage for your hosting setup:

URLWhat it shows
http://IP:3000/statusFriendly HTML dashboard for all servers
http://IP:3000/api/statusJSON for all servers (API)
http://IP:3000/api/status/my-serverJSON for a single server by slug
http://IP:3000/s/my-serverShareable HTML card for a single server

Sharing a server

Every server gets a short share link based on its subdomain/slug. Send it to a friend and they see a live preview card with:

  • Server name, game type, version and MOTD
  • Online player count and max players
  • Ping latency and RAM usage
  • Direct connect address (IP:port)

Integrating the status JSON

Because /api/status is unauthenticated JSON, you can point a bot, dashboard or embed at it:

json — example
{
  "panel_name": "NetherPanel",
  "updated_at": "2026-09-14T12:00:00.000Z",
  "servers": [
    {
      "name": "Survival",
      "slug": "survival",
      "status": "running",
      "address": "192.168.1.42:25565",
      "online_players": 9,
      "max_players": 20,
      "query_latency": 12
    }
  ]
}

The slugs shown here come from the server's subdomain you set at creation time. Pick something short and shareable.
