Troubleshooting

The most common NetherPanel issues, and how to fix them.

Java not found

Using Termux, Java servers need the ubuntu proot-distro with Java 25 installed:

bash
proot-distro install ubuntu
proot-distro login ubuntu -- apt update && apt install -y openjdk-25

If the panel itself needs Java on the host (not usually the case):

bash
pkg install openjdk-25

Node.js not found

bash
pkg install nodejs

Then re-run bash setup.sh to install npm dependencies.

Port already in use

Set PORT to something free and restart:

bash
PORT=8080 npm start

To stop the running panel first: bash stop.sh (or the recorded pid-file stop in start.sh).

Bedrock Dedicated Server on ARM devices

The official Bedrock Dedicated Server only supports x86_64 CPUs. On ARM phones the panel shows a clear error. Solution: pick PocketMine-MP or Nukkit/PowerNukkit instead — both run great on devices.

PocketMine needs its PHP runtime

PocketMine-MP uses PMMP's prebuilt Android ARM64 PHP runtime, auto-downloaded to data/pmmpphp/ on first use. If the download fails (bad network), delete the folder and start the server again.

Server won't start

  1. Check the console tab for the exact error — most failures print a Java exception or a download message.
  2. Confirm the software jar downloaded fully (check data/servers/<server>/ for a truncated .jar file).
  3. Try Restart, then Kill + Start if it's stuck.
  4. Watch device memory — a server can silently die on OOM. Reduce RAM allocation.

First boot is slow

Normal. The panel downloads the server jar and (for Fabric/Forge) may install loaders. On mobile connections this can take a few minutes. Subsequent boots are fast.

Forgot an account password

Admins can reset a user's password from the admin dashboard. As the root operator you can also create a fresh admin:

bash
node create-admin.js mynewadmin strongpass123
