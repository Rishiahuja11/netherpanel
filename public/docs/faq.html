FAQ

Quick answers to the questions people ask most.

Can my phone really run a Minecraft server?

Yes — but top-end devices fare best. For small groups of players (a handful of friends) on Paper or PocketMine, a mid-range Android works fine. Expect fan noise and battery drain on older phones; keep it plugged in while hosting.

How do friends join my server?

Friends on the same Wi-Fi join using your phone's local IP + port, e.g. 192.168.1.42:25565 (shown on the server page). For friends outside your network you need port forwarding on your router or a tunnel — that is outside NetherPanel's scope.

Do I need Docker?

No. Unlike Pterodactyl, NetherPanel runs servers as real processes — Java inside a proot Ubuntu container, Bedrock natively. Lightweight by design.

Do I need a domain or FQDN?

No. Everything works out of the box over IP:port. No Cloudflare, no tunnels, no DNS.

Can I stop people registering?

Yes. Admin → Settings → uncheck registration enabled (set registration_enabled=false).

Can I install plugins/mods easily?

Yes — built-in mod manager searches Modrinth, Hangar and Poggit, filters by your server's loader, and installs with one click.

Can Bedrock and Java players play together?

Not natively. NetherPanel runs Java servers (Paper, Forge…) or Bedrock servers (PocketMine, Nukkit) as separate servers. Cross-play would need a proxy like Geyser on the Java side, which you can install via the mod manager.

Are backups automatic?

Backups are manual by default, but you can automate them with Schedules (cron) to trigger backup commands on a timer.

Is there an API?

Yes — the panel exposes a JSON REST API. Users can generate personal API tokens for external bots and scripts. See Users & Permissions.

How do I update NetherPanel?

bash
cd netherpanel
git pull
bash setup.sh
bash start.sh

Your data/ folder (servers, backups, database) is untouched by git pull.
