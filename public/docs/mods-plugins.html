Mods & Plugins

Search, install and manage mods (for Forge/Fabric/NeoForge) and plugins (for Paper/Spigot/Purpur/Folia/PocketMine) directly from the panel. NetherPanel pulls from Modrinth, Hangar and Poggit.

Overview

NetherPanel integrates with three major plugin/mod repositories:

SourceContentServer types
HangarPaper/Spigot/Purpur/Folia pluginsPaper, Spigot, Purpur, Folia
ModrinthMods (Forge, Fabric, NeoForge, Quilt) and pluginsForge, Fabric, NeoForge, Quilt, Paper, Spigot, Purpur, Folia
PoggitPocketMine-MP phar pluginsPocketMine

Each server type automatically searches its primary source. You can also force a specific source in the install dialog.

Searching for Mods & Plugins

  1. Open your server in the panel and click Mods & Plugins in the sidebar.
  2. Type a search query (e.g. "EssentialsX", "Spark", "WorldEdit").
  3. Results come from the appropriate source for your server type.
  4. Click a result to see its description, versions and supported Minecraft versions.

Installing a Mod or Plugin

  1. Find the mod/plugin you want in the search results.
  2. Select a version (the panel defaults to the latest compatible version).
  3. Click Install.
  4. The file is downloaded to your server's plugins/ or mods/ directory.
  5. Restart or reload your server to load the new mod/plugin.

Always restart your server after installing or removing mods/plugins. Hot-reloading is not supported by most server software.

Managing Installed Mods & Plugins

The mods/plugins list shows all installed items with their status:

  • Toggle on/off — disables a plugin by renaming the file to .disabled. Re-enable to restore it.
  • Remove — deletes the file from disk and removes the database record.
  • Version info — shows the installed version number.

Loader-Aware Downloads

NetherPanel automatically filters mod versions by loader. When you install a mod on a Forge server, only Forge-compatible versions are shown. The same applies to Fabric, NeoForge and other loaders.

For plugin servers (Paper, Spigot, etc.), only versions with compatible loaders (paper, spigot, folia, bukkit) are selected. This prevents accidentally installing an incompatible mod version.

Forcing a Source

By default, each server type uses its primary source. You can override this in the install dialog by selecting a different source:

  • Hangar — Paper/Spigot plugins hosted on hangar.papermc.io
  • Modrinth — Mods and plugins from modrinth.com
  • Poggit — PocketMine plugins from poggit.pmmp.io

Troubleshooting

No results found

  • Try a different search query (e.g. "essentials" instead of "essentialsx").
  • Check that your server type supports the source you're searching.
  • Some mods/plugins may have been removed from the repository.

Install failed

  • Ensure your server has enough disk space.
  • Check that the version you selected matches your server's Minecraft version.
  • For mod servers, ensure the loader (Forge, Fabric, etc.) matches.

Mod/plugin not loading after install

  • Restart your server (stop then start, not just reload).
  • Check the server console for error messages.
  • Verify the mod/plugin version is compatible with your server version.
  • Some plugins require additional dependencies — check the plugin's documentation.
