Server Types

NetherPanel supports 13 Minecraft server software variants across Java and Bedrock editions. Each type is tested with the latest available version.

Java Edition Servers

Java servers run inside proot-distro Ubuntu on Termux. All Java servers require the java binary inside the proot environment.

Vanilla

The official Minecraft server from Mojang. No mod/plugin support.

Typevanilla
GameJava
Latest version26.2
Mods/PluginsNone
Download sourceMojang official

Paper

High-performance Spigot fork with bug fixes and optimizations. Excellent plugin compatibility.

Typepaper
GameJava
Latest version26.2
Mods/PluginsBukkit plugins via Hangar / Modrinth
Download sourcePaperMC Fill API v3

Spigot

Modified CraftBukkit with performance improvements and plugin API. Downloads the Paper compatibility jar.

Typespigot
GameJava
Latest version26.2
Mods/PluginsBukkit plugins via Hangar
Download sourcePaperMC (Spigot-compatible build)

Purpur

Paper fork with additional configuration options and gameplay tweaks. Full Paper plugin compatibility.

Typepurpur
GameJava
Latest version26.2
Mods/PluginsBukkit plugins via Hangar
Download sourcePurpurMC API

Folia

Paper's multithreaded scheduler. Plugins must be Folia-compatible for full support.

Typefolia
GameJava
Latest version26.2
Mods/PluginsFolia/Paper plugins via Hangar / Modrinth
Download sourcePaperMC Fill API v3

Forge

The most popular mod loader. Supports thousands of mods for Minecraft.

Typeforge
GameJava
Latest version26.2 (build 65.1.x)
Mods/PluginsForge mods via Modrinth
Download sourceMinecraft Forge Maven

The panel resolves the correct Forge build number automatically from the promotions_slim.json manifest.

NeoForge

Community-driven fork of Forge with modernized codebase. Uses a launcher-based startup.

Typeneoforge
GameJava
Latest version26.2.0.88
Mods/PluginsNeoForge mods via Modrinth
Download sourceNeoForge Maven

NeoForge uses a @unix_args.txt launcher instead of a standalone server jar. NetherPanel handles this automatically via the startup_cmd mechanism.

Fabric

Lightweight, modern mod loader with fast updates for new Minecraft versions.

GameJava
Latest version26.2
Mods/PluginsFabric mods via Modrinth
Download sourceFabric Meta API

Quilt

Fork of Fabric with additional features. Server jar availability varies by version.

Typequilt
GameJava
Latest version26.2
Mods/PluginsQuilt mods via Modrinth
Download sourceQuilt Meta API

Choosing a Server Type

Not sure which to pick? Paper is the best all-around choice for most Java servers. It has excellent performance, plugin support, and is the most widely tested. For modded gameplay, choose Forge or Fabric based on the mods you want.

  • Vanilla — vanilla gameplay, no plugins, simplest setup
  • Paper — best performance + plugin support (recommended for most users)
  • Spigot — classic plugin server, slightly older than Paper
  • Purpur — Paper + extra configuration options
  • Folia — multithreaded, for advanced plugin developers
  • Forge — largest mod ecosystem
  • Fabric — lightweight, fast updates for new Minecraft versions
  • NeoForge — modern Forge fork with active development
  • PocketMine — Bedrock plugins (PHP-based)
  • Nukkit — Bedrock plugins (Java-based, PowerNukkitX)
