Admin Panel

The admin dashboard (shield icon in the top nav) gives admins full control over users, servers and panel settings — no database queries needed.

Accessing the admin panel

  1. Log in as an admin user (the default admin account or any user created with the admin role).
  2. A shield icon appears in the top nav bar — click it, or go to /admin.html directly.

Non-admin users see no shield icon and /admin.html returns 403.

Overview tab

The first screen shows live stats: total users, total servers, total admins. No data to read — it updates on every page load from the database.

Users tab

Full CRUD on user accounts:

  • Add User — create accounts for friends or teammates; optionally enable must change password so they pick one on first login
  • Edit — change username or role (user ↔ admin)
  • Reset Password — set a temporary password
  • Delete — remove an account (irreversible)

To create an admin from the terminal instead: node create-admin.js <user> <pass> [email]

Servers tab

See all servers across all users, with quick-start/stop/restart controls and a one-click delete button. Useful for handling abuse or crashed servers without asking the owner to do it.

Server deletion is permanent. Files, backups and logs are removed immediately.

Settings tab

Adjust panel-wide defaults:

SettingDefaultWhat it controls
panel_nameNetherPanelName shown in the dashboard header and status pages
default_ram1024Default RAM (MB) when creating a new server
default_ram_max2048Max RAM (MB) cap in the server wizard
registration_enabledtrueWhether new users can self-register via the login page
max_servers_per_user5Cap on servers each user can create

Egg templates

NetherPanel ships with 8 built-in templates covering the most common server types:

TemplateType
VanillaJava — official Mojang jar
PaperJava — optimized Spigot fork
FabricJava — lightweight mod loader
ForgeJava — popular modding platform
NeoForgeJava — community-driven Forge fork
PocketMine-MPBedrock — PHP-based, runs natively on Termux
Nukkit (PowerNukkit)Bedrock — Java-based, runs via proot
Bedrock Dedicated ServerBedrock — official Mojang binary (x86_64 only)

Templates provide default download URLs, start commands and java arguments. They cannot be edited from the UI but can be extended by adding entries in src/database.js.
