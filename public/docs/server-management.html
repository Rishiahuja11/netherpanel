Server Management

Every server gets its own page with a real-time console, file manager, backups, mod manager, schedules and player management.

Console

The console is a real-time terminal (xterm.js). Server output streams live; type a command and hit Enter to send it to the game's stdin.

examples
say Hello, NetherPanel!
list
op Rishiahuja1
whitelist add Steve
stop

Command history is preserved for the session — press ↑ to revisit commands.

Power controls

From the server page (or the dashboard) you can:

  • Start — boot the server process
  • Stop — graceful stop (issues stop to the server)
  • Restart — stop then start again
  • Kill — force-kill if the server is hung

Prefer Stop over Kill — kills can corrupt worlds. Kill is for hung processes only.

File manager

Files live under data/servers/<server>/. The web file manager lets you:

  • Browse directories and preview text files
  • Edit files directly in the browser (with save)
  • Upload files from your device
  • Create directories and rename/delete items

Backups

  • Create — snapshot the server directory into data/backups/
  • Download — pull a backup archive to your device
  • Restore — put a backup back over the current server files

Restoring overwrites current files. Make a current backup first if you might want it back.

Mod / plugin manager

Search and install from three sources:

SourceBest for
ModrinthFabric, Forge, NeoForge, Quilt mods and Paper plugins
HangarPaper, Velocity and Waterfall plugins
PoggitPocketMine-MP plugins

The manager auto-detects the server's loader and only shows compatible files. Install and remove with one click, then restart the server to apply changes.

Schedules

Create cron-based schedules that run commands or power actions automatically. Examples:

cron
0 3 * * *      # every night at 03:00 → run /restart
0 */6 * * *    # every 6 hours      → say "Auto backup happening"
15 2 * * 0     # every Sunday 02:15  → /backup start

Players

The player manager covers whitelist, operators (ops) and bans. Add/remove players by username without touching config files.

Monitoring

Each server page shows live resource usage: memory, CPU and disk. A crash is analysed automatically, and auto-restart is offered so your world comes back without babysitting.
