Getting Started

NetherPanel runs a full Minecraft server panel right on your Android phone, inside Termux. No cloud, no Docker, no domain — just IP:port access.

Requirements

  • Termux (Android) — download from F-Droid or GitHub releases
  • Node.js — installed automatically by the setup script
  • Java 25 — installed inside the Ubuntu proot-distro container
  • proot-distro with the ubuntu distribution — used to run Java servers

Quick start (2 minutes)

1. Clone and run setup

bash
git clone https://github.com/Rishiahuja11/netherpanel.git
cd netherpanel
bash setup.sh

This installs Node.js, Java, proot-distro, npm dependencies, and creates the data/ directory. It is idempotent — safe to re-run.

2. Start the panel

bash
bash start.sh

Open http://localhost:3000 in your phone's browser.

3. Log in

Default admin credentials are pre-seeded on the very first run:

UsernamePasswordNote
adminadmin123Change this immediately

On the first login the panel forces you to set a new password. Do it.

How it works

  1. Termux runs natively on your Android device — it is the shell.
  2. NetherPanel is an Express.js web server running inside that shell, bound to port 3000.
  3. Java servers spawn inside a proot-distro Ubuntu container with Java 25 — they are real JVM processes.
  4. Bedrock servers (PocketMine-MP, Nukkit) run natively in Termux — PocketMine uses an auto-downloaded ARM64 PHP runtime; no system PHP is needed.
  5. Official Bedrock Dedicated Server is x86_64-only and will show a helpful error on ARM64 devices.

Unlike Pterodactyl, there are no containers, wings daemons, or FQDN requirements. That is what makes NetherPanel a 2-minute setup.
