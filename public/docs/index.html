What is NetherPanel?

NetherPanel is a self-hosted Minecraft server management panel built for Termux on Android. It runs natively in your terminal, manages real server processes, and gives you a full Pterodactyl-style web UI — without Docker or a domain.

Worlds, configs, plugins and logs live on your device under data/servers/. Every server is reachable at your local IP (e.g. 192.168.1.x:25565), and the panel itself at http://localhost:3000.

Why so light? Unlike Pterodactyl, there's no Docker, containers or wings daemon. Java servers spawn as real processes inside a proot-distro Ubuntu container; Bedrock servers run natively. Setup takes about two minutes.
