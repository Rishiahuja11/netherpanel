Backups

Create point-in-time backups of your server files and restore them when needed. Backups capture your entire server directory including worlds, plugins, configuration and mods.

Creating a Backup

  1. Open your server in the panel.
  2. Click Backups in the sidebar.
  3. Click Create Backup.
  4. Enter a name for the backup (e.g. "before-update", "world-reset").
  5. Click Create.

The backup process runs in the background. A progress indicator shows the status. Large servers may take a few minutes.

Viewing Backups

The backups list shows all available backups with:

  • Name — your descriptive name for the backup.
  • Size — compressed file size.
  • Created — timestamp of when the backup was made.
  • Actions — download, restore or delete.

Restoring a Backup

Restoring a backup overwrites all current server files. The server is stopped before restoration and must be started manually afterwards.

  1. Find the backup you want to restore in the list.
  2. Click Restore.
  3. Confirm the action in the dialog.
  4. Wait for the restoration to complete.
  5. Start your server.

Downloading a Backup

You can download any backup as a compressed file to your device:

  1. Click the Download button next to the backup.
  2. The file downloads to your device's download folder.
  3. Extract with any zip utility (7-Zip, WinRAR, etc.).

Backup Retention

The admin can configure how many days backups are kept. After this period, old backups are automatically deleted. The default retention is 30 days.

Configure this in Admin → Settings → Backup retention days.

Best Practices

  • Backup before updates — always back up before updating server software or mods/plugins.
  • Name descriptively — use names like "pre-1.21-update" or "clean-world" for easy identification.
  • Download important backups — keep off-device copies of critical backups.
  • Test restores — occasionally restore a backup to verify it works.
  • Monitor disk space — backups consume storage; delete old ones you no longer need.
