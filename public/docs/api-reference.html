API Reference

NetherPanel provides a REST API for all operations. Authenticate with a JWT token and pass it in the Authorization header.

Base URL

url
http://localhost:3000/api

All endpoints are prefixed with /api. Responses are JSON.

Authentication

POST /api/auth/login

Returns a JWT token for API access.

request
POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123"
}
response 200
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "id": 1,
    "username": "admin",
    "role": "admin"
  }
}

POST /api/auth/register

Create a new user account (if registration is enabled).

request
POST /api/auth/register
Content-Type: application/json

{
  "username": "alice",
  "email": "alice@example.com",
  "password": "securepass123"
}

GET /api/auth/me

Returns the authenticated user's profile.

header
Authorization: Bearer <token>

Servers

GET /api/servers

List all servers the authenticated user has access to.

response 200
[
  {
    "id": 1,
    "name": "My Server",
    "server_type": "paper",
    "version": "26.2",
    "status": "running",
    "port": 25565,
    "ram_min": 512,
    "ram_max": 1024,
    "subdomain": "myserver",
    "address": "myserver:25565"
  }
]

POST /api/servers

Create a new server. Downloads the server software automatically.

request
POST /api/servers
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "My Paper Server",
  "version": "26.2",
  "server_type": "paper",
  "game_type": "java",
  "ram_min": 512,
  "ram_max": 1024,
  "subdomain": "myserver",
  "java_args": "",
  "template_id": null
}

GET /api/servers/:id

Get detailed information about a specific server.

PUT /api/servers/:id

Update server settings (name, version, RAM, java_args, startup_cmd, subdomain).

DELETE /api/servers/:id

Permanently delete a server and all its files. Requires owner or admin role.

POST /api/servers/:id/start

Start the server. Returns {"status": "running"}.

POST /api/servers/:id/stop

Gracefully stop the server. Returns {"status": "stopped"}.

POST /api/servers/:id/restart

Restart the server (stop then start).

POST /api/servers/:id/kill

Force-kill the server process immediately.

GET /api/servers/:id/console

Returns the last 200 lines of console output.

response 200
[
  { "line": "[12:34:56] [Server thread/INFO]: Done (1.234s)!" },
  { "line": "[12:34:56] [Server thread/INFO]: For help, type 'help'" }
]

POST /api/servers/:id/command

Send a command to the server console.

request
{ "command": "say Hello World" }

GET /api/servers/versions?software=:type

List available versions for a server type. Returns an array of version strings.

example
GET /api/servers/versions?software=paper

["26.2", "26.1.2", "26.1.1", "26.1", "26.0.2", ...]

Files

GET /api/servers/:id/files?path=

List files and directories at the given path (relative to server root). Use empty string for root.

response 200
[
  { "name": "server.properties", "isDirectory": false, "size": 1234 },
  { "name": "world", "isDirectory": true, "size": 0 },
  { "name": "plugins", "isDirectory": true, "size": 0 }
]

GET /api/servers/:id/files/read?path=:file

Read a file's contents. Max 5MB.

PUT /api/servers/:id/files/write

Write content to a file. Creates parent directories if needed.

request
{ "path": "server.properties", "content": "server-port=25565\n..." }

DELETE /api/servers/:id/files

Delete a file or directory.

request
{ "path": "old-world" }

PUT /api/servers/:id/files/rename

Rename or move a file.

request
{ "oldPath": "old-name.txt", "newPath": "new-name.txt" }

POST /api/servers/:id/files/mkdir

Create a directory.

request
{ "path": "new-folder" }

POST /api/servers/:id/files/upload

Upload files via multipart form. Field name: files. Max 10 files per request.

GET /api/servers/:id/files/download?path=:file

Download a file as a binary stream.

Mods & Plugins

GET /api/servers/:id/mods

List all installed mods/plugins for a server.

GET /api/servers/:id/mods/search?q=:query&limit=20

Search for mods/plugins. Source is determined by server type (Hangar, Modrinth, or Poggit).

response 200
{
  "source": "hangar",
  "total_hits": 302,
  "hits": [
    {
      "id": "EssentialsX_Selectors",
      "title": "EssentialsX_Selectors",
      "description": "...",
      "author": "DogLoverPink",
      "downloads": 12345
    }
  ]
}

POST /api/servers/:id/mods/install

Install a mod/plugin from the repository.

request
{
  "mod_id": "EssentialsX_Selectors",
  "version_id": null,
  "source": "hangar",
  "name": "EssentialsX_Selectors"
}

For Modrinth installs, source is "modrinth" and mod_id is the Modrinth project ID.

DELETE /api/servers/:id/mods/:modId

Remove a mod/plugin (deletes file and database record).

PUT /api/servers/:id/mods/:modId/toggle

Enable or disable a mod/plugin by renaming the file to .disabled.

request
{ "enabled": false }

Backups

GET /api/servers/:id/backups

List all backups for a server.

POST /api/servers/:id/backups

Create a new backup.

request
{ "name": "pre-update-backup" }

POST /api/servers/:id/backups/:backupId/restore

Restore a backup. Overwrites all current server files.

DELETE /api/servers/:id/backups/:backupId

Delete a backup permanently.

GET /api/servers/:id/backups/:backupId/download

Download a backup file.

Schedules

GET /api/servers/:id/schedules

List all schedules for a server.

POST /api/servers/:id/schedules

Create a new schedule.

request
{
  "name": "Nightly Restart",
  "cron_expression": "0 3 * * *",
  "action": "restart",
  "command": null
}

Actions: restart, stop, start, backup, command.

PUT /api/servers/:id/schedules/:scheduleId

Update a schedule's settings.

DELETE /api/servers/:id/schedules/:scheduleId

Delete a schedule.

POST /api/servers/:id/schedules/:scheduleId/run

Manually trigger a schedule immediately.

Access Control

GET /api/servers/:id/access

List all users with access to a server.

POST /api/servers/:id/access

Grant a user access to a server.

request
{
  "userId": 2,
  "role": "member",
  "permissions": ["view", "console", "files"]
}

Roles: owner, admin, member.

Permissions: view, console, files, config, power, backups, schedules, mods, players, access.

PUT /api/servers/:id/access/:userId

Update a user's role or permissions.

DELETE /api/servers/:id/access/:userId

Revoke a user's access to a server.

Player Management

GET /api/servers/:id/players/whitelist

POST /api/servers/:id/players/whitelist

DELETE /api/servers/:id/players/whitelist

GET /api/servers/:id/players/ops

POST /api/servers/:id/players/ops

DELETE /api/servers/:id/players/ops

GET /api/servers/:id/players/bans

POST /api/servers/:id/players/bans

DELETE /api/servers/:id/players/bans

Admin Endpoints

All admin endpoints require the admin role.

GET /api/admin/settings

List all panel settings.

PUT /api/admin/settings

Update panel settings.

GET /api/admin/users

List all users.

Error Responses

All errors return a JSON object with an error field:

error response
{
  "error": "Server not found"
}
HTTP StatusMeaning
400Bad request — invalid JSON, missing fields, or validation error
401Unauthorized — missing or invalid token
403Forbidden — insufficient permissions
404Not found — server, file or endpoint doesn't exist
500Internal server error

Rate Limits

Authentication endpoints (login, register) are rate-limited to 15 requests per 10-minute window. Other endpoints have no explicit rate limits.
