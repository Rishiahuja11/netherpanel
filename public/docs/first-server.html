Creating Your First Server

The panel handles downloads, port allocation and config generation — you just pick the software and click Create.

1. Open the Create Server wizard

  1. Open the panel at http://localhost:3000 and log in.
  2. On the dashboard, click Create Server. The quick-start wizard appears.

2. Choose game type & software

FamilyAvailable softwareNotes
Java EditionVanilla, Paper, Spigot, Purpur, Folia, Fabric, Forge, NeoForge, QuiltRuns via proot Ubuntu + Java 25
Bedrock · PocketMinePocketMine-MPNative ARM64 PHP runtime, auto-downloaded
Bedrock · NukkitPowerNukkit / PowerNukkitXUses proot Java; no official Nukkit releases exist
Bedrock · OfficialBedrock Dedicated Serverx86_64 only — not available on ARM phones

Each template comes pre-configured — the right jar URL, a default start command and sensible arguments. Pick one and the wizard fills everything in.

3. Resources

  • Name — display name shown in the dashboard.
  • Subdomain — a short slug used in the share/status URL like /s/my-server.
  • Port — automatically allocated for you (default 25565), or pick your own.
  • RAM — memory limit in MB for the Java process (-Xmx / -Xms).
  • Java args — advanced Java 25 flags; sensible defaults are set.

RAM is capped by your phone. Give a server only as much as you can spare — the operating system still needs memory. 1–2 GB is typical for a small server.

4. Create & start

Hit Create Server. The panel will:

  1. Create the server's directory under data/servers/.
  2. Download the required software (jar or PocketMine runtime).
  3. Generate server.properties, the start command and default files.

Then just press Start. The first boot downloads/installs dependencies, so be patient — especially on mobile networks.

5. Join your server

Your server's address is your device's local IP plus the allocated port. From the server page the panel shows the ready address, e.g.:

address
192.168.1.42:25565

Add it as a server in Minecraft Java / Bedrock and connect. IP:port access means no domain, no tunnel, no Cloudflare.

Signs of a healthy boot: a green Running status and console output ending in "Done (X.Xs)! For help, type 'help'".
