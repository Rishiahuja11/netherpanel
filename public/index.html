Cloudflare & Domain

When enabled, servers get an address like myserver.smp45.qzz.io. When disabled, servers show localhost:port.
Log in with your Cloudflare account email and password. If 2FA is enabled you'll be asked for the code from your authenticator app. This replaces API tokens — the panel stores the session securely. "Continue with GitHub" opens Cloudflare's official GitHub login in a new tab. GitHub login can only happen in your browser and won't give the panel a token — use email & password (or an API token) for automatic tunnel creation.
After logging in, the panel automatically checks your domains and creates a Cloudflare Tunnel so the panel is reachable at panel.<domain>. It restarts with the panel on every boot.
